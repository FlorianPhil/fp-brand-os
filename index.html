THREAD

How the system works.

Source of truth to generated output

The goal is not another static brand book. The goal is a compact source system that can generate a website direction, collateral, copy, and channel rules from approved strategic decisions.

A

Strategy contract.

Focus Star turns the strategy into decisions an AI can reuse without re-interpreting the brand.

B1

Creative direction.

Style sliders, archetypes, moodboard, type, color, and signature device translate strategy into a first visual direction.

B2

Identity rules.

Look, feel, voice, and signature rules tighten the selected direction into reusable constraints.

C

Application references.

Examples and channel rules show how the approved strategy and identity behave in real formats.

REVIEW

Review order.

Do not inspect everything at once

Approve the upstream decision layer first, then the identity translation, then application examples. If a downstream page reveals a better decision, edit the source and rebuild.
